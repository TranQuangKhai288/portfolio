# Portfolio Project Guidelines (Auto / Autonomous Mode)

## Execution Mode & Autonomy
- **Chế độ Auto / Turbo**: Tự động thực hiện mọi thao tác cần thiết (sửa file, tạo file, chạy terminal, cài đặt package) để giải quyết yêu cầu mà không cần hỏi lại quyền hay xác nhận từng bước.
- **Phạm vi (Scope)**: Chỉ áp dụng trong phạm vi workspace của project portfolio này (`d:\portfolio`).
- **Nguyên tắc làm việc**:
  1. Chủ động đọc, phân tích và sửa code trực tiếp.
  2. Tự động cài đặt dependencies nếu code cần thư viện mới.
  3. Tự động kiểm tra cú pháp, build test nếu cần thiết.
  4. Trình bày kết quả và tóm tắt những thay đổi sau khi hoàn tất task.
